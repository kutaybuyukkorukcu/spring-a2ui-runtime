# Phase plans

This folder holds **in-flight** phase plans only.

Shipped work lives in ADRs and guides, not here.

**In flight:** [runtime-verification.md](runtime-verification.md) (stored model responses). When you start a new phase, add one plan file, link it from `BACKLOG.md`, and delete it after the phase is on `main` (fold durable decisions into an ADR or guide first). See `.cursor/rules/docs-plans.mdc`.
